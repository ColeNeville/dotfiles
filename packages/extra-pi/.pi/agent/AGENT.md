# Pi Agent Guidelines

## Commit Policy

**Never commit unless explicitly asked.** Always use the commit skill when committing:

1. Ask what from the working tree should be committed
2. Stage only the specific files that belong in this commit (never `git add -A`)
3. Inspect staged changes to determine type, scope, and content
4. Write a conventional commit message
5. Run the commit skill's commit command

Do not auto-commit changes.
