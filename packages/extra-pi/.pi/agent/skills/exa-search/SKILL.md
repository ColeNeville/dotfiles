# Exa Web Search

Search the web using the Exa MCP server.

## Usage

Call the `exa_web_search_exa` MCP tool with a relevant query string.

## Guidelines

- Use this skill whenever the user asks to search, look up, find online, get the latest, or any query requiring current information.
- Craft specific, focused queries for best results.
- If the initial results are not specific enough, refine and search again.
