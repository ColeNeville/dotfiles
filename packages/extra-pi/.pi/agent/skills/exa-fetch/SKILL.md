# Exa Web Fetch

Read a webpage's full content using the Exa MCP server.

## Usage

Call the `exa_web_fetch_exa` MCP tool with the target URL.

## Guidelines

- Use this skill when you have a URL and need the actual page content.
- Prefer this over relying on internal knowledge for current or detailed page content.
- Often used after `exa-search` to read full articles from search results.
